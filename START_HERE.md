# Start here

1. Install Node.js 22.13+.
2. Run `npm ci` in this project folder.
3. Run `npx expo start` and open with compatible Expo Go on Android/iOS.
4. For PDF/DOCX/OCR or research summaries, follow the backend setup in `README.md` and add its address/access code in app Settings.

This is the complete new React Native source project, including backend, fonts, icons, lockfiles and tests. Build/setup and validation details are in `README.md`.
